BRAM Serializer 동작 관측 기록
================================

테스트 입력: PMOD로 5회 저장한 8비트 병렬 값 x0~x4
직렬 출력 표기: 실제 전송은 바이트별 LSB-first이나, 아래는 가독성을 위해
             각 8비트를 통상 표기(MSB..LSB)로 적고 {x4 x3 x2 x1 x0} 순으로 나열함.

병렬 입력
x0 = 0010_0001
x1 = 0100_0010
x2 = 0110_0100
x3 = 1001_1000
x4 = 1000_1011

예상되는 직렬 출력  {x4  x3  x2  x1  x0}
1000_1011_1001_1000_0110_0100_0100_0010_0010_0001

실제 직렬 출력      {x4  x3  x2  x1  x0}
1010_0011_1001_1000_0110_0100_0100_0010_0010_0001

[관측된 불일치]
첫 바이트(x4)만 예상 1000_1011 과 실제 1010_0011 이 다르고, 나머지
x3~x0 바이트는 일치한다. 원인은 미규명 상태의 관측 기록이다.
