# 3비트 가감산기 하드웨어 구조

## 1. 개요

이 회로는 Zybo Z7-20 보드에서 동작하는 3비트 가감산기이다.

- `mode = 0` : `A + B`
- `mode = 1` : `A - B = A + ~B + 1`

입력 `A`, `B`는 3비트 unsigned 값이며, 결과는 4비트 `sum[3:0]`로 출력된다.

---

## 2. 전체 구조

```text
             +---------------------------+
A[2:0] ----->|                           |
             |   3-bit Adder/Subtractor  |-----> sum[3:0]
B[2:0] ----->|                           |
             |   mode=0 : A + B          |-----> c_out
mode ------->|   mode=1 : A + ~B + 1     |
             +---------------------------+
```

내부적으로는 1비트 `full_adder` 3개를 직렬 연결하여 구성한다.

```text
                 mode
                   |
B[0] -- XOR -------+----> FA0 ---- carry[1] ----> FA1 ---- carry[2] ----> FA2
A[0] -------------------> | sum[0]               | sum[1]               | sum[2]
carry[0] = mode --------> |

B[1], B[2]도 각각 mode와 XOR된 뒤 각 full adder에 입력된다.
최종 carry/borrow 정보는 sum[3], c_out 생성에 사용된다.
```

---

## 3. 보드 입출력 매핑

| 신호       | 보드 자원            | 의미                      |
| ---------- | -------------------- | ------------------------- |
| `a[2:0]`   | `SW0, SW1, SW2`      | 입력 A                    |
| `mode`     | `SW3`                | `0: ADD`, `1: SUB`        |
| `b[2:0]`   | `BTN0, BTN1, BTN2`   | 입력 B                    |
| `sum[3:0]` | `LD0, LD1, LD2, LD3` | 연산 결과                 |
| `c_out`    | `RGB LED Red (LD5)`  | SUB 결과가 음수일 때 점등 |

---

## 4. 출력 해석

### 결과 LED

- `LD0 ~ LD3`는 `sum[3:0]`를 표시한다
- 덧셈 결과는 0부터 14까지 4비트로 표현된다
- 뺄셈 결과가 음수이면 4비트 2의 보수 형태로 표시된다

### 음수 표시 LED

- `LD5`는 ADD 모드에서는 항상 꺼진다
- `LD5`는 SUB 모드에서 `A < B`일 때만 켜진다
- 즉, `LD5 = 1`이면 결과가 음수라는 의미이다

예시:

- `3 - 4 = 1111`, `LD5 = ON` -> `-1`
- `5 - 2 = 0011`, `LD5 = OFF` -> `+3`
- `0 - 7 = 1001`, `LD5 = ON` -> `-7`

---

## 5. 핵심 요약

- `full_adder` 3개를 연결하여 3비트 가감산기를 구성
- `mode` 신호 하나로 덧셈과 뺄셈을 선택
- 뺄셈은 `A + ~B + 1` 방식의 2의 보수 연산으로 구현
- 결과는 `LD0 ~ LD3`에 2진수로 표시
- `LD5`는 뺄셈 결과가 음수일 때만 켜짐
