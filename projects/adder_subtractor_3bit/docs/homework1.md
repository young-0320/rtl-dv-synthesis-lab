
# 과제 1: Zybo Z7 기반 3비트 가감산기 설계

## 📅 마감 기한: 2026년 3월 27일 10:30

## 1. 설계 사양 

3비트 Unsigned 정수 두 개(**$a, b$**)를 입력받아, 선택된 모드에 따라 덧셈 또는 뺄셈을 수행하는 하드웨어를 구현.

* **연산 핵심** : 1비트 Full Adder 모듈을 `generate` 구문으로 $N$(3)번 인스턴스화하여 구성.
* **연산 모드** :
* `mode 0`: 덧셈 (**$A + B$**)
* `mode 1`: 뺄셈 (**$A - B \rightarrow A + \bar{B} + 1$**)
* **핵심 로직** : 뺄셈 시 `mode` 신호를 **$B$** 입력의 XOR 반전 신호 및 최하위 비트의 `cin`으로 사용하여 **2의 보수** 연산을 구현.

---

## 2. 하드웨어 리소스 맵핑

Zybo Z7-20 보드 사용

| **분류** | **신호명 (RTL)** | **하드웨어 핀 (Zybo)** | **비고**                    |
| -------- | ---------------- | ---------------------- | --------------------------- |
| **입력** | `a[2:0]`         | **SW0, SW1, SW2**      | 피감수/피가산수 (상태 유지) |
| **입력** | **`mode`**       | **SW3**                | **0: ADD / 1: SUB**         |
| **입력** | `b[2:0]`         | **BTN0, BTN1, BTN2**   | 감수/가산수 (누를 때 입력)  |
| **출력** | `sum[3:0]`       | **LD0, LD1, LD2, LD3** | 연산 결과 (4비트 표시)      |
| **출력** | `c_out`          | **RGB LED (Red)**      | 최종 캐리/빌림 발생 확인    |

---

## 3. 주요 설계 메커니즘 

1. **계층적 구조 (Hierarchical Structure)** :

* `full_adder.v`: $A, B, C_{in}$을 입력받아 $Sum, C_{out}$을 출력하는 기본 단위.
* `adder_subtractor_3bit.v`: `genvar`를 이용해 `full_adder`를 3번 복제하여 연결.

2. **가감산 통합 로직** :

* `b_in = b ^ mode;` : `mode`가 1일 때만 **$B$**를 비트 반전(1의 보수).
* `assign carry[0] = mode;` : `mode`가 1일 때 최하위 `cin`에 1을 더해 **2의 보수** 완성.

3. **결과 가독성** :

* `output [3:0] sum` : 3비트 연산의 최대값(**$7+7=14$**)을 수용하기 위해 4비트로 확장하여 LED로 출력.
