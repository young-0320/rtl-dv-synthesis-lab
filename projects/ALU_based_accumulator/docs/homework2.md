# 과제 2: ALU 기반 누산기

## 📅 마감 기한: 2026년 4월 3일 10:30

## 1. 설계 사양

수업때 만들었던 ALU를 기반으로

누적되는 출력 시스템으로 만들고 비디오로 보여주기. (버튼 누를때 마다, 현재 f의 기능을 현재까지의 값을 사용하여 연산)

(코드를 보고하지 않거나 비디오 설명을 이해할 수 없으면 감점 요소임. 현재 어떻게 돌아가고 있는지 설명을 해야함.

설명은 비디오의 음성 또는 보고서로 해도 됨.)

버튼으로 클록을 생성할때 바운싱이 생겨 한꺼번에 여러번 수행 될 수 있음.  디바운싱 활용하여 코딩 하면 됨.

조건: a: 스위치 3개

    b: 스위치 1개  (0을 보내거나 r을 보냄.)

    f: 버튼 2개  (+1, -1 기능 제거)

    reset: 버튼 1개

    진행 (클록): 버튼 1개

r: LED 활용

---

## 2. 입력

* `a[2:0]`: 외부 스위치 값(unsigned int 3 bit)
* `b`: 0 -> 0, 1 ->현재 `r`
* `f`: ALU 기능 선택(+, -, *)
* `go`: 진행 버튼
* `reset`: 초기화 버튼

출력

`r`: signed int 5bit

## 내부 상태

* `r`: 현재까지 저장된 결과

## 동작

버튼 `go`를 한 번 누를 때마다:

1. `a`를 읽음
2. `b`에 따라 두 번째 입력을 결정(두 번째 입력을 R이라고 설정)

* `0`
* 또는 `r`

1. `f`에 따라 연산 수행
   1. `f` : 00 -> a + R
   2. `f` : 01 -> a - R
   3. `f` : 10 -> a * R
   4. `f`: 이외의 입력(default) ->don't care 출력(r <=5'bx;)
2. 연산 결과를 `r`에 저장
3. 5개의 LED에 `r` 표시
   1. 만약 오버플로가 발생할 시 LD5에 빨란불 들어옴
   2. overflow 발생 시 아래의 정책에 따라 행동

## 3. overflow 정책

Wrap-around

`over`는 가장 최근의 유효한 `go` 연산의 결과가 signed 5-bit 표현 범위를 벗어났을 때 1로 저장되며, 새 연산 결과로 덮어쓴다. reset 입력 인가 시 0으로 초기화

## 4. 하드웨어 매핑

Zybo Z7-20 보드 사용

| **분류** | **신호명** | **하드웨어 핀 (Zybo)**          | **비고**                  |
| -------------- | ---------------- | ------------------------------------- | ------------------------------- |
| **입력** | `a[2:0]`       | **SW3, SW2, SW1**               | unsigned                        |
| **입력** | `b`            | **SW0**                         | 0또는 1, mux 제어신호           |
| **입력** | `f[1:0]`       | **BTN1, BTN0**                  | 덧셈/뺄셈/곱셈                  |
| **입력** | `reset`        | **BTN2**                        | `r`과 `over`을 0으로 초기화 |
| **입력** | `go`           | **BTN3**                        | 클럭/진행 버튼                  |
| **출력** | `r[4:0]`       | **LD3, LD2, LD1, LD0, LD6(G))** | 연산 결과 (5비트 표시)          |
| **출력** | `over`         | **RGB LD5 (R)**                 | 오버플로 발생시  점등         |
